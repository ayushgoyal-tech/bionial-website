## Project Overview
This is the static website for Bionial Lifesciences, a nutraceutical 
contract manufacturer in Mohali, Punjab.

## Tech Stack
- Single-page static HTML/CSS/JS website
- Hosted on GitHub Pages with custom domain bioniallife.com
- Lucide icons via CDN
- Google Fonts (Playfair Display + DM Sans)

## File Structure
- index.html — The entire website (single file)
- CNAME — Custom domain configuration for GitHub Pages

## Design Guidelines
- Colors: Navy (#0B1D3A), Teal (#0D9488), Gold (#C9A84C), Cream (#FAF8F2)
- Fonts: Playfair Display (headings), DM Sans (body)
- Style: Professional B2B pharma/nutraceutical aesthetic
- Mobile responsive with breakpoints at 1024px, 768px, 480px

## Important Context
- Company: Bionial Lifesciences, Plot 459, Sector-82, JLPL, Mohali
- Tagline: Precision Nutraceutical Manufacturing. Built for Brands That Scale.
- Services: Contract manufacturing, private labeling, custom formulation, 
  regulatory support
- Products: Capsules, tablets, syrups, powders, sachets
